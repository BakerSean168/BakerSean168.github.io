前端技术栈
● 框架：React 18 + TypeScript
● 桌面应用：Tauri（Rust + Web 技术）
● UI 组件：Ant Design
● 状态管理：Redux/Mobix
● 实时通信：WebSocket
● 构建工具：Vite

后端技术栈
● API 服务：Python FastAPI
● AI 处理：Python + Transformers + PyTorch
● 语音识别：OpenAI Whisper+（流式集成）
● 大语言模型：Ollama + 通用大模型
● 数据库：SQLite + SQLAlchemy
● 异步处理：Celery + Redis

AI 模型选择
● 语音转写：Whisper Large V3（多语言支持）
● 文本摘要：通用大模型
● 翻译模型：NLLB-200 / M2M-100
● 嵌入模型：BGE / Sentence-Transformers
